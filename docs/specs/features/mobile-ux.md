# 모바일 UX 명세

## 기능 개요

FileHatch는 반응형 웹 디자인을 적용하여 모바일 브라우저에서도 전체 기능을 사용할 수 있다.
브레이크포인트 기반으로 레이아웃을 재구성하며, 터치 인터랙션에 최적화된 UX를 제공한다.

---

## 반응형 디자인

### 브레이크포인트

| 구분 | 조건 | 적용 |
|------|------|------|
| 데스크톱 | `min-width: 769px` | 기본 레이아웃 |
| 모바일 | `max-width: 768px` | 모바일 최적화 레이아웃 |

### CSS 적용 방식

각 컴포넌트의 CSS 파일과 `global.css`에 미디어 쿼리를 적용한다.

```css
/* 컴포넌트별 CSS 파일 내 */
@media (max-width: 768px) {
    .component-class {
        /* 모바일 스타일 */
    }
}
```

---

## CSS 변수

레이아웃 크기를 CSS 변수로 관리하여 일관성을 유지한다.

```css
:root {
    --header-height: 64px;
    --mobile-header-height: 56px;
    --sidebar-width: 240px;
    --details-panel-width: 350px;
}
```

## 레이아웃 변경 (768px 이하)

### 요소별 비교

| 요소 | 데스크톱 | 모바일 |
|------|----------|--------|
| Header | 높이 64px, 전체 너비 | 높이 56px, 콤팩트 구성 + 햄버거 메뉴 아이콘 |
| Sidebar | 240px 고정 좌측 | 숨김 상태, 오버레이로 슬라이드 (z-index: 1200) |
| FileInfoPanel | 350px 우측 사이드바 | 바텀 시트 (max-height: 55vh) |
| 파일 그리드 | 멀티 컬럼 | 싱글 컬럼 |
| 업로드 패널 | 사이드 패널 | 하단 패널 |
| FAB | 없음 | MobileFAB.tsx 플로팅 버튼 (업로드) |

### Header

```
데스크톱:
+-------------------------------------------------------+
| Logo  | 검색바            | 알림  사용자메뉴          |
+-------------------------------------------------------+
  64px

모바일:
+-------------------------------------------------------+
| 햄버거 | Logo | 검색 아이콘  | 알림  사용자메뉴        |
+-------------------------------------------------------+
  56px
```

- 데스크톱: 로고, 검색바, 알림, 사용자 메뉴를 한 줄에 배치
- 모바일: 검색바를 아이콘으로 축소, 햄버거 메뉴 아이콘 추가

### Sidebar

```
데스크톱:                         모바일 (열린 상태):
+--------+------------------+    +--------+------------------+
|        |                  |    | 오버레이 | 반투명 배경       |
| 사이드바 |   메인 콘텐츠     |    | (240px)|  (클릭시 닫힘)    |
| 240px  |                  |    |        |                  |
|        |                  |    |        |                  |
+--------+------------------+    +--------+------------------+
                                  z-index: 1200
```

- 데스크톱: 좌측에 240px 고정 사이드바
- 모바일: 기본 숨김 상태, 햄버거 메뉴 클릭 시 오버레이로 슬라이드 표시
- 오버레이 외부 영역 클릭 시 사이드바 닫힘

### FileInfoPanel (파일 상세 패널)

```
데스크톱:                         모바일:
+------------------+--------+    +------------------------+
|                  |        |    |                        |
|   메인 콘텐츠     | 상세   |    |      메인 콘텐츠        |
|                  | 패널   |    |                        |
|                  | 350px  |    +========================+
+------------------+--------+    |   바텀 시트 (55vh)      |
                                 |   파일 상세/미리보기      |
                                 |   태그 등               |
                                 +------------------------+
```

- 데스크톱: 우측 350px 사이드바로 파일 상세 정보 표시
- 모바일: 하단에서 올라오는 바텀 시트 (최대 높이 55vh)
- 바텀 시트 내용: 파일 상세 정보, 미리보기, 태그

### 파일 그리드

- 데스크톱: 화면 너비에 따라 멀티 컬럼 배치
- 모바일: 싱글 컬럼으로 전환, 파일 항목을 세로로 나열

### MobileFAB (플로팅 액션 버튼)

```
모바일 화면:
+------------------------+
|                        |
|      파일 목록          |
|                        |
|                        |
|                   [+]  |  <-- MobileFAB.tsx
+------------------------+
```

- 데스크톱에서는 표시하지 않음
- 모바일에서만 우측 하단에 플로팅 버튼 표시
- 클릭 시 파일 업로드 동작 트리거

## 터치 인터랙션

### 제스처 매핑

| 제스처 | 데스크톱 대응 | 모바일 동작 |
|--------|-------------|------------|
| 탭 (tap) | 클릭 | 파일 선택 |
| 더블 탭 (double-tap) | 더블 클릭 | 파일/폴더 열기 |
| 길게 누르기 (long-press) | 우클릭 | 컨텍스트 메뉴 표시 |
| 스와이프 (swipe) | - | 향후 제스처 확장 예정 |

### 터치 타겟 크기

모든 인터랙티브 요소는 최소 터치 타겟 크기를 준수한다.

```css
/* 최소 터치 타겟: 44x44px (Apple HIG 기준) */
.touch-target {
    min-width: 44px;
    min-height: 44px;
}
```

### 안전 영역 (노치 기기)

노치가 있는 기기(iPhone X 이상 등)에서 콘텐츠가 가려지지 않도록 안전 영역을 적용한다.

```css
/* 노치 기기 하단 안전 영역 */
.bottom-fixed-element {
    padding-bottom: env(safe-area-inset-bottom);
}
```

## 비활성화 기능 (모바일)

터치 환경에서 의미가 없거나 오작동 가능한 기능은 모바일에서 비활성화한다.

| 기능 | 사유 |
|------|------|
| 마퀴 선택 (Marquee selection) | 터치 드래그와 충돌, 터치 기기에서 비활성화 |
| 키보드 내비게이션 | 모바일 환경에서 물리 키보드 미사용 전제 |
| 드래그 앤 드롭 업로드 | 제한적 지원 (MobileFAB으로 대체) |

## 파일 선택 동작

### 모바일 파일 인터랙션

| 동작 | 결과 |
|------|------|
| 탭 | 파일 선택 (단일 선택) |
| 더블 탭 | 파일 열기 / 폴더 진입 |
| 길게 누르기 | 컨텍스트 메뉴 (복사, 이동, 삭제, 이름 변경, 공유 등) |

### 컨텍스트 메뉴

- 데스크톱: 마우스 우클릭으로 트리거
- 모바일: 길게 누르기(long-press)로 트리거
- 동일한 메뉴 항목 제공

## 구현 가이드

### 미디어 쿼리 적용 패턴

```css
/* 기본: 데스크톱 스타일 */
.sidebar {
    width: var(--sidebar-width);
    position: fixed;
    left: 0;
    top: var(--header-height);
}

/* 모바일 오버라이드 */
@media (max-width: 768px) {
    .sidebar {
        transform: translateX(-100%);
        z-index: 1200;
        transition: transform 0.3s ease;
    }

    .sidebar--open {
        transform: translateX(0);
    }

    .sidebar-overlay {
        position: fixed;
        inset: 0;
        background: rgba(0, 0, 0, 0.5);
        z-index: 1199;
    }
}
```

### 바텀 시트 패턴

```css
/* FileInfoPanel 바텀 시트 (모바일) */
@media (max-width: 768px) {
    .file-info-panel {
        position: fixed;
        bottom: 0;
        left: 0;
        right: 0;
        max-height: 55vh;
        border-radius: 16px 16px 0 0;
        box-shadow: 0 -4px 16px rgba(0, 0, 0, 0.12);
        overflow-y: auto;
        z-index: 1100;
        transition: transform 0.3s ease;
    }
}
```

### MobileFAB 패턴

```css
.mobile-fab {
    display: none;  /* 데스크톱에서 숨김 */
}

@media (max-width: 768px) {
    .mobile-fab {
        display: flex;
        position: fixed;
        bottom: calc(24px + env(safe-area-inset-bottom));
        right: 24px;
        width: 56px;
        height: 56px;
        border-radius: 50%;
        background: #3182F6;
        color: white;
        align-items: center;
        justify-content: center;
        box-shadow: 0 4px 12px rgba(49, 130, 246, 0.4);
        z-index: 1000;
    }
}
```

## 테스트 체크리스트

### 모바일 UX 검증 항목

| 항목 | 검증 내용 |
|------|----------|
| 레이아웃 전환 | 768px 이하에서 모바일 레이아웃으로 정상 전환 |
| 사이드바 | 햄버거 메뉴 클릭 -> 오버레이 사이드바 표시 -> 외부 클릭 시 닫힘 |
| 파일 상세 | 파일 선택 시 바텀 시트로 상세 정보 표시 |
| MobileFAB | 모바일에서만 플로팅 버튼 표시, 클릭 시 업로드 동작 |
| 터치 타겟 | 모든 버튼/링크 최소 44x44px |
| 노치 영역 | 하단 고정 요소가 노치에 가려지지 않음 |
| 컨텍스트 메뉴 | 길게 누르기로 정상 표시 |
| 파일 선택 | 탭으로 선택, 더블 탭으로 열기 |
| 마퀴 선택 | 터치 기기에서 비활성화 확인 |
| 가로/세로 전환 | 화면 회전 시 레이아웃 정상 유지 |
